# Skills

This directory contains [Agent Skills](https://agentskills.io/) : plain-markdown guidance that AI coding assistants load on demand.

- [lmakefile](lmakefile) : write, review and debug Lmakefiles — the open-lmake paradigm, rule authoring, classic pitfalls, stateful tools, verification loop.

Installation instructions (Claude Code, claude.ai, Codex, Cursor, other agents) are in the
[AI assistants](../doc/src/ai_assistants.md) chapter of the documentation,
rendered at <https://cesar-douady.github.io/open-lmake/ai_assistants.html>.

The skills are written for humans as much as for agents :
the in-depth reference files under `lmakefile/references/` are included verbatim as chapters of the documentation book
(good practices, coming from other build systems, stateful tools, FAQ), so skill and documentation cannot diverge.
